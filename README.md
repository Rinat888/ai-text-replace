# AI Replace для MX Master 3S

Скрипт заменяет выделенный текст ответом от **DeepSeek** (или другого ИИ) по нажатию кнопки мыши.

## Как это работает

1. Выделяете текст в любом приложении
2. Нажимаете кнопку на мыши
3. Скрипт копирует выделенный текст (Ctrl+C)
4. Отправляет его в ИИ-API с вашим промтом
5. Ответ вставляется на место выделенного текста (Ctrl+V)

## Текущая конфигурация

- **Провайдер:** DeepSeek (deepseek-chat)
- **API:** `https://api.deepseek.com/v1`
- **Ключ:** уже настроен в `.env`

## Поддерживаемые провайдеры

- **DeepSeek** (deepseek-chat, deepseek-reasoner)
- **OpenAI** (GPT-4o, GPT-4, GPT-3.5 и др.)
- **Anthropic Claude** (Sonnet, Opus, Haiku)
- **OpenAI-совместимые** (LM Studio, Ollama, vLLM, LocalAI, Groq, Together AI и др.)

## Быстрый старт

Всё уже настроено. Выполните только:

### 1. Установите Python 3.10+

Скачайте с [python.org](https://www.python.org/downloads/). При установке **отметьте галочку «Add Python to PATH»**.

### 2. Установите keyboard (желательно)

```cmd
pip install keyboard
```

Библиотека `keyboard` не обязательна, но делает эмуляцию Ctrl+C / Ctrl+V надёжнее (уже установлена).

### 3. Привяжите к кнопке мыши

1. Откройте **Logitech Options+**
2. Выберите мышь MX Master 3S
3. Нажмите на кнопку, которую хотите назначить
4. Выберите **«Другое действие»** → **«Запуск приложения»**
5. Укажите путь: **`C:\Users\User\Desktop\проект\run_ai_replace.bat`**
6. Готово!

### 4. Пользуйтесь

- Выделите текст → нажмите кнопку мыши → ответ ИИ заменит текст
- Время ответа: обычно **1-3 секунды**

## Как пользоваться файлом `config.json`

`config.json` — это главный пульт управления скриптом. В нём вы задаёте:

- **Что** делать с текстом (промт)
- **Кто** будет это делать (провайдер и модель)
- **Как** именно (температура, длина ответа и т.д.)

Файл находится в той же папке, что и скрипт, и загружается при каждом запуске. Если вы его удалите — скрипт покажет пример и выключится.

### Чтобы изменить настройки:

1. Откройте `config.json` в любом редакторе (хоть в Блокноте)
2. Поменяйте нужное поле
3. Сохраните файл
4. Всё — при следующем нажатии кнопки настройки уже будут новыми

Ничего перезапускать не надо. Скрипт читает конфиг каждый раз заново.

## Разбор каждого параметра в `config.json`

### `provider` — провайдер API

Кого скрипт будет дёргать за ответом. Два варианта:

- `"openai"` — OpenAI, DeepSeek и любой совместимый сервер (через OpenAI-формат)
- `"anthropic"` — Anthropic Claude

**Пример:** `"provider": "openai"`

---

### `api_key_env` — имя переменной с ключом

Указывает, из какой переменной в `.env` брать API-ключ. Если вы в `.env` написали `OPENAI_API_KEY=sk-...`, то здесь должно быть `"OPENAI_API_KEY"`. Для Anthropic — `"ANTHROPIC_API_KEY"`.

**Пример:** `"api_key_env": "OPENAI_API_KEY"`

---

### `model` — модель ИИ

Название модели, которую вы хотите использовать. Разные провайдеры — разные названия:

- **DeepSeek:** `deepseek-chat`, `deepseek-reasoner`
- **OpenAI:** `gpt-4o`, `gpt-4o-mini`, `gpt-4-turbo`, `o3-mini`
- **Claude:** `claude-sonnet-4-20250514`, `claude-opus-4-20250514`, `claude-haiku-3-5-20241022`

**Пример:** `"model": "deepseek-chat"`

---

### `prompt` — что сделать с текстом ★

Это основная инструкция, которая говорит ИИ: «вот текст, сделай с ним то-то». Внутри промта **обязательно** должно быть `{text}` — именно сюда скрипт подставит выделенный текст.

**Пример:**
```
"prompt": "Перепиши текст живым человеческим языком, но сохрани деловой тон:\n\n{text}"
```

- `\n` — это перенос строки (чтобы отделить инструкцию от самого текста)
- `{text}` — плейсхолдер, заменяется на ваш выделенный текст при отправке

---

### `system_prompt` — системная роль ИИ ★

Это НЕ инструкция к действию, а **описание роли**. Вы говорите модели: «ты — такой-то специалист, работай в таком-то стиле». Это задаёт общий тон и поведение.

**Пример:**
```
"system_prompt": "Ты — опытный редактор. Отвечай только готовым текстом без всяких пояснений."
```

#### В чём разница между `prompt` и `system_prompt`?

|                     | `system_prompt`                                       | `prompt`                                            |
|---------------------|-------------------------------------------------------|-----------------------------------------------------|
| **Что это**         | Роль и рамки поведения модели                         | Конкретная задача с конкретным текстом              |
| **Используется как** | Установка один раз — на весь диалог                   | К каждому запросу — новый (меняется текст)          |
| **Что писать**      | «Ты — редактор. Работай молча, только текст на выход» | «Перепиши следующий текст живым языком:\n\n{текст}» |
| **Метафора**        | Должностная инструкция сотрудника                     | Конкретное поручение, что надо сделать прямо сейчас  |

**Простыми словами:** `system_prompt` объясняет ИИ, *кто он такой* и *в каком стиле работает*. А `prompt` говорит, *что именно* нужно сделать с *конкретным* текстом.

Если `system_prompt` пустой (`""`) — ничего страшного, скрипт просто отправит один только `prompt`.

### `temperature` — температура (креативность)

Число от `0` до `2`. Чем выше — тем более творческие и разнообразные ответы. Чем ниже — тем более строгие и предсказуемые.

- **`0.0 – 0.3`** — строго, сухо, по шаблону (хорошо для правки ошибок, форматирования)
- **`0.5 – 0.8`** — баланс (хорошо для рерайта и перевода)
- **`1.0 – 2.0`** — креативно, непредсказуемо (хорошо для генерации идей)

**Пример:** `"temperature": 0.7`

---

### `max_tokens` — максимальная длина ответа

Ограничение на длину ответа в токенах (токен — это примерно ¾ слова, или 1 слово, или 3-4 символа русского текста). Если ответ получается слишком длинным — можно уменьшить. Если обрезается — увеличить.

**Пример:** `"max_tokens": 4096` (это примерно 2500-3000 слов — с запасом)

---

### `api_base` — адрес API

URL, куда скрипт отправляет запрос.

- **DeepSeek:** `https://api.deepseek.com/v1`
- **OpenAI:** `https://api.openai.com/v1`
- **LM Studio (локально):** `http://localhost:1234/v1`
- **Ollama (локально):** `http://localhost:11434/v1`

**Пример:** `"api_base": "https://api.deepseek.com/v1"`

---

### `delay_before_copy` — задержка перед Ctrl+C

Сколько секунд скрипт ждёт, прежде чем скопировать текст. Нужно, чтобы система успела обработать нажатие кнопки мыши до того, как скрипт попытается что-то копировать. Обычно хватает 0.2 секунды.

**Пример:** `"delay_before_copy": 0.2`

---

### `delay_before_paste` — задержка перед Ctrl+V

Сколько секунд скрипт ждёт перед вставкой ответа. Нужно, чтобы буфер обмена успел обновиться и приложение было готово принять вставку. Если ответ вставляется не туда или с задержкой — чуть увеличьте это значение.

**Пример:** `"delay_before_paste": 0.3`

## Примеры промтов (prompt)

| Задача | prompt |
|--------|--------|
| Исправить ошибки | `Исправь орфографические и грамматические ошибки, сохранив стиль:\n\n{text}` |
| Перевод на английский | `Переведи на английский язык:\n\n{text}` |
| Живой деловой стиль (текущий) | `Перепиши текст живым человеческим языком, но с деловым тоном. Поправь грамматику и структуру:\n\n{text}` |
| Сократить | `Сократи текст до 2-3 предложений, сохранив суть:\n\n{text}` |
| Написать ответ | `Напиши вежливый ответ на это письмо:\n\n{text}` |

## Как сменить провайдера

### На OpenAI

В `config.json`:
```json
"provider": "openai",
"api_base": "https://api.openai.com/v1",
"model": "gpt-4o"
```
В `.env` заменить: `OPENAI_API_KEY=sk-ваш-ключ-openai`

### На Claude

В `config.json`:
```json
"provider": "anthropic",
"model": "claude-sonnet-4-20250514"
```
В `.env` заменить: `ANTHROPIC_API_KEY=sk-ant-ваш-ключ`

### На локальный LLM (LM Studio / Ollama)

В `config.json`:
```json
"provider": "openai",
"api_base": "http://localhost:1234/v1",
"model": "local-model"
```
В `.env`: `OPENAI_API_KEY=not-needed`

## Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Ничего не происходит | Запустите `python ai_replace.py` и посмотрите ошибки |
| Текст не копируется | Установите `keyboard`: `pip install keyboard` |
| Ошибка 401 | Проверьте API-ключ в `.env` |
| Ошибка 402 (баланс) | Пополните баланс DeepSeek |
| Долгий ответ | Уменьшите `max_tokens` в config.json |
| Вставляется не то | Уточните `system_prompt` в config.json |
| Выделенный текст не подставляется в промт | Проверьте, что в `prompt` есть `{text}` |

### Запуск в режиме отладки

```cmd
cd C:\Users\User\Desktop\проект
python ai_replace.py
```

Вы увидите все сообщения об ошибках в консоли.
